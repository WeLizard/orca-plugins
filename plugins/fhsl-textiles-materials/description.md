# Textiles & Materials

48 seamless 2048 × 2048, 8-bit grayscale PNG height maps for OrcaSlicer texture displacement.

**Important:** the textures show up only after the pack is activated. In OrcaSlicer, open the menu (☰) next to **File** in the top-left corner, go to the **Plugins** tab and switch this pack on. If only some maps appear on Windows, update the pack to 1.0.2 or newer.

Install this pack as a plugin, then select a map under **Texture libraries → FilamentHub Surface Library — Textiles & Materials**.
